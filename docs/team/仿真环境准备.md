2026-09-20核验：[官方0.9.15发布页](https://github.com/carla-simulator/carla/releases/tag/0.9.15)提供[Windows安装包](https://downloads.carlasim.com/Windows/CARLA_0.9.15.zip)，大小7,755,135,185字节，已下载、通过全包CRC校验并解压。PyPI提供匹配Python3.10的`carla-0.9.15-cp310-cp310-win_amd64.whl`。这是固定版本的工程选择，不声称是最新版本。客户端与服务器0.9.15一致，连续帧与单车油门/刹车测试通过，运行步骤和边界见[首个驾驶实验](首个驾驶实验.md)。

本机实测RTX4060 Laptop显存8188MiB、内存约15.6GiB，E盘剩余约164GiB。先用低画质、小地图、单车、少传感器验证，不承诺复杂场景帧率。客户端用独立Python环境，不混入感知环境。预编译包解压至无空格英文路径，例如`E:\Simulators\CARLA_0.9.15`；下载包和运行输出不提交仓库。

第一阶段验收是官方示例生成车辆、读取连续帧位置与速度、低速行驶、制动停车并退出；保存日志与画面。之后逐项接入学长算法：平台状态先转换成算法需要的坐标、速度和障碍物，再将目标速度和转向转换成CARLA控制。尤其旧主链的`throttle`是m/s目标速度，CARLA的油门是比例，必须增加速度控制环节，不能照抄数值。

可提前验证跟车、制动、路径跟踪、避障与泊车逻辑；本届地图坐标、车型参数、场景命名和扣分条件仍需赛事平台校准。CARLA运行通过与赛事评分通过分别记录。

## 本机检查

编译器负责将 C++ 源码转换为可执行程序；SDK 提供调用仿真器的接口；仿真器及授权负责加载场景并推进车辆状态。三者分别验证，不能用其中一项通过代替整个环境可用。

在仓库根目录运行（Windows、Python 3）：

```powershell
python tools/check_driving_environment.py
# 取得SDK后，把下面路径换成实际解压目录
python tools/check_driving_environment.py --sdk-root "E:\SimOne\SimOneAPI"
```

检查工具寻找已安装的 Visual Studio C++ x64 工具，在子进程中加载开发环境，编译并运行 `tests/cpp/toolchain_smoke.cpp`。不修改系统环境变量，不启动仿真器。日志、程序和 `report.json` 保存在忽略目录 `work/driving_environment/`。

退出码0仅表示编译器小程序通过；1表示编译器检查失败；无效参数为2。必须同时阅读报告中的SDK缺失项。`--sdk-root`检查的是旧工程所需的代表性文件，文件齐全也不等于版本兼容或授权有效。

本轮实测 MSVC 工具集14.44.35207编译、链接、运行均通过。普通终端PATH中未找到CMake，已检查的Visual Studio目录也未定位到CMake；不据此宣称整台电脑没有安装。真实SDK尚未提供，因此本轮未验证学长工程构建。其CMakeLists依赖SDK上层工程的路径与构建函数，不能直接当作独立项目编译。

## 官方文档与接入顺序

- [SimOne开发快速开始](https://simone-docs.51sim.com/20_Developer_Manual/01_Developer_Quick_Start/index.html)：SDK与示例位于安装目录中的SimOneAPI。
- [接口调用示例](https://simone-docs.51sim.com/20_Developer_Manual/12_Call_Example/index.html)：包括ACC、AVP、TrajectoryControl等。
- [通用产品安装手册](https://simone-docs.51sim.com/02_installation-and-deployment/2.2.%20installation/index.html)：涉及产品许可，不等于比赛授权或本届配置要求。

先取得匹配的客户端、SDK和训练权限，再运行官方示例。之后只做一个最小闭环：读取位置和速度 → 下发低速目标 → 观察下一帧响应 → 停车并正常退出。最后才接入学长完整策略，便于区分环境问题和算法问题。所有构建输出放源码目录之外。

等待环境期间可在有来源哈希的开发副本中修复策略文件校验、数组越界和角度区间判断，并用不依赖SDK的反例验证。原始 `code_pre/` 保持不动。其他仿真器可以用于独立算法实验，但需要接口适配，其运行结果不能代替比赛平台验证。
