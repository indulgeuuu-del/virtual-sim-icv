# 驾驶与泊车开发路线

核验日期：2026-09-20。当前目标是2027届智能网联汽车设计，现有代码来自2025交接。本文区分规则依据、开发安排和已完成验证。

## 当前主线

[正式命题与运行](http://gcxia.shiyukeji.com:10801/upload/20260512/1778571778824.pdf)第3页要求利用平台提供的虚拟车载传感器环境感知信息，自主开发决策控制算法。[正式评分与规则](http://gcxia.shiyukeji.com:10801/upload/20260512/1778571778948.pdf)第9至11页列出41类驾驶/泊车场景，当前保存版本未发现独立“视频检测计数并提交Excel”的要求。这不等于宣布后续补充通知永远不会增加任务。

主要数据流是：平台给出车辆位置、速度、障碍物与地图 → 程序决定停车、跟车或变道 → 计算目标速度与转向 → 平台推进下一帧。`perception/` 的视频计数没有接在这条驾驶链路上。

四人建议分别负责场景规则与决策、路径与控制、泊车、平台集成与评测。以可运行的小场景协作，不要求先共同学习或训练YOLO。

## 仿真环境选择

| 选择 | 用途 | 进入开发的条件 |
| --- | --- | --- |
| 赛事NEVCsim本地端及配套SDK | 优先复用学长工程，最终验证比赛兼容性 | 取得安装包、有效授权、SDK、可加载场景 |
| 通用SimOne | 同一接口体系的本地实验候选 | 核对具体产品版本、许可、地图与接口差异 |
| CARLA | 独立的驾驶算法实验后备方案 | 核验硬件/系统/版本，跑官方示例，再适配少量输入输出 |
| CarSim + Simulink | 有明确车辆动力学研究需求时再考虑 | 许可证与相关模型，不作为默认环境 |

“官方赛事入口暂不可进入”不代表其他仿真器不能用，也不证明赛事客户端可以无授权运行。2024手册写明NEVCsim本地端需要云端生成的license。

2026-09-20实测 [SimOne文档](https://simone-docs.51sim.com/index.html)可访问；根地址存在异常跳转，应使用完整链接。[当前安装手册](https://simone-docs.51sim.com/02_installation-and-deployment/2.2.%20installation/index.html)描述协作版/企业版客户端，并涉及授权加密狗问题。这证明有本地产品与公开文档，不证明拥有可用安装包、免费许可或与比赛一致的SDK。不要把通用产品手册的安装建议直接当比赛配置要求。

SDK是程序与仿真器通信的头文件、库及示例。学长主链的 `throttleMode=Speed` 表示目标速度（m/s）；CARLA常用油门比例输入，迁移需要速度控制器，不能简单替换函数名。地图查询、坐标、挡位和逐帧同步也需适配。其他平台跑通不能代替官方评分。

## 里程碑与验收

| 阶段 | 交付物 | 通过标准 |
| --- | --- | --- |
| 1. 环境条件核验 | 软件/SDK来源、版本、授权方式、工具链、样例场景清单 | 每项有实际文件或官方来源；未取得项明确标注 |
| 2. 最小闭环 | 运行官方示例；读取状态、发送低速控制、停车、正常退出 | 连续帧状态和控制日志可对应，无失配或失控 |
| 3. 驾驶开发副本 | 从交付基线复制必要源码并记录原件哈希 | 保留code_pre；实际SDK编译，修复已确认高风险问题 |
| 4. 单场景回归 | 制动、车道跟踪、灯光/停止线、跟车、泊车测试 | 保存地图/车型/参数、运行日志及实际分数或失败依据 |
| 5. 连续与泛化 | 场景组回归、变更对照、压力/边界条件 | 多次运行稳定，新增策略不破坏已通过项 |

环境调查期间可以核验策略文件、区间判断、坐标变换及空输入，不必等待官网。取得比赛SDK后优先继承，暂时无法取得时用CARLA验证可迁移的小模块，不预先重写整套获奖工程。

## 实验记录

每次运行记录代码提交号、未提交差异、仿真器/SDK版本、场景实际名称、地图/车型、参数、运行结果与评分依据。评分编号、命题展示编号、平台caseName、历史caseIdx分别核对。

直接在main协作的流程见 [团队指南](README.md)。更改公共控制/几何代码前说明影响模块；同步队友改动后重跑相关验证。官方训练开放与SDK许可不明时保留待确认项，不把缺少资料变成无限等待。
