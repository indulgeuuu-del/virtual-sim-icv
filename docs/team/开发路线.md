## 首个目标场景：前方车辆静止

### 规则与测量

依据[正式评分规则](http://gcxia.shiyukeji.com:10801/upload/20260512/1778571778948.pdf)物理第11页表3：评分ID为1，命题ID为7，基准100分。前方静止干扰车相距60m，测试车初速30km/h（约8.33m/s）。停车后间距1～3.5m扣50分，超过3.5m、碰撞或耗时超过300s计0分。

这些距离的测量参考点及端点比较方式仍需平台核实，不能自行把公式解释当作官方实现。初期先以低速、大间距验证控制链路，再进行30km/h、60m条件的实验。低速调试通过不等于正式场景通过，也不以贴近前车争取满分作为首次调试目标。

首轮记录两车位置、朝向、包围盒、车速、仿真时间、帧号、油门/制动/转向、碰撞和车道偏移。在同一直道且两车朝向一致的限定下，用前后车包围盒计算纵向车身净距；另记中心距离，避免将二者混用。弯道或错位车辆需重新定义距离算法。

### 继承代码对应位置

以下相对路径均基于交付主基线的TrajectoryControl/src，原件保留。

| 位置 | 实际作用 | 迁移时核对 |
| --- | --- | --- |
| main.cpp | 按模式选择main_manual、main_follow或main_track | 有效策略文件会影响入口，不能直接假定本题进入main_track |
| main_track.cpp:18 | 更新障碍与主车状态 | 同帧数据、邻域索引有效性 |
| main_track.cpp:97 | 为障碍构造停止线 | 障碍归类及停止线位置 |
| main_track.cpp:119 | 用速度平方等项估计制动距离 | 原模型系数不直接用于CARLA车型 |
| main_track.cpp:120 | 距离判定含固定4.38046偏移 | 源注释称质心到车头距离，需核对车型与参考点 |
| core/vehicle.cpp:44 | 使用Speed控制模式 | throttle为m/s目标速度 |
| core/vehicle.cpp:282 | 调用SetDrive发送控制 | CARLA需要油门/制动比例，另建速度控制环节 |

主思路是“前方障碍变成停车约束，结合当前速度判断何时减速”。保留这一思路，坐标、车身尺寸、制动响应和平台接口分别验证，不直接拷贝固定数值。当前还没有证明此通用分支就是旧比赛该场景的实际运行分支。
