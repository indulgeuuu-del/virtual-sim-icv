# 首个驾驶实验：前方车辆静止

本实验服务2027赛题驾驶主线。CARLA是独立实验环境，不代表官方评分复现。

## 正式要求与实验阶段

依据[正式评分规则](http://gcxia.shiyukeji.com:10801/upload/20260512/1778571778948.pdf)物理第11页表3：评分ID为1，命题ID为7，基准100分。前方静止干扰车相距60m，测试车初速30km/h（约8.33m/s）。停车后间距1～3.5m扣50分，超过3.5m、碰撞或耗时超过300s计0分。

这些距离的测量参考点及端点比较方式仍需平台核实，不能自行把公式解释当作官方实现。初期先以低速、大间距验证控制链路，再进行30km/h、60m条件的实验。低速调试通过不等于正式场景通过，也不以贴近前车争取满分作为首次调试目标。

首轮记录两车位置、朝向、包围盒、车速、仿真时间、帧号、油门/制动/转向、碰撞和车道偏移。在同一直道且两车朝向一致的限定下，用前后车包围盒计算纵向车身净距；另记中心距离，避免将二者混用。弯道或错位车辆需重新定义距离算法。

## 学长代码对应位置

以下相对路径均基于交付主基线的TrajectoryControl/src，原件保留。

| 位置 | 实际作用 | 迁移时核对 |
| --- | --- | --- |
| main.cpp | 按模式选择main_manual、main_follow或main_track | 有效策略文件会影响入口，不能直接假定本题进入main_track |
| main_track.cpp:18 | 更新障碍与主车状态 | 同帧数据、邻域索引有效性 |
| main_track.cpp:97 | 为障碍构造停止线 | 障碍归类及停止线位置 |
| main_track.cpp:119 | 用速度平方等项估计制动距离 | 原模型系数不直接用于CARLA车型 |
| main_track.cpp:120 | 距离判定含固定4.38046偏移 | 源注释称质心到车头距离，需核对车型与参考点 |

| core/vehicle.cpp:282 | 调用SetDrive发送控制 | CARLA需要油门/制动比例，另建速度控制环节 |

主思路是“前方障碍变成停车约束，结合当前速度判断何时减速”。保留这一思路，坐标、车身尺寸、制动响应和平台接口分别验证，不直接拷贝固定数值。当前还没有证明此通用分支就是旧比赛该场景的实际运行分支。

## 环境验收入口

客户端独立放在忽略目录work/carla/venv。Python客户端相当于遥控器，完整Windows安装包才是运行地图和车辆的仿真器；只装客户端不能运行仿真。

```powershell
python -m venv work/carla/venv
work/carla/venv/Scripts/python.exe -m pip install carla==0.9.15
work/carla/venv/Scripts/python.exe tools/check_carla_environment.py
# 完整仿真器启动后执行：
work/carla/venv/Scripts/python.exe tools/check_carla_environment.py --connect
```

检查脚本仅观察，不加载地图、不生成车辆、不修改仿真设置。连接检查需服务器自行推进帧；若服务器处于同步等待状态，超时应由原控制程序推进解决。报告明确区分客户端导入、服务器连续帧、驾驶及比赛验证，退出码0不表示车辆已经行驶。

后续顺序：官方示例与画面验证 → 单车沿车道低速行驶及停车 → 加入静止前车 → 30km/h/60m实验 → 不同速度、间距、车型重复回归。仿真器完整安装包未就绪前不生成驾驶通过结论。

## 单车接口测试运行

先启动仿真器（路径按本机安装位置调整）：

```powershell
& 'E:\Simulators\CARLA_0.9.15\WindowsNoEditor\CarlaUE4.exe' -quality-level=Low -windowed -ResX=800 -ResY=600
```

等待地图加载后，在仓库根目录运行：

```powershell
work/carla/venv/Scripts/python.exe tools/check_carla_environment.py --connect
work/carla/venv/Scripts/python.exe tools/carla_control_smoke.py
```

接口测试会重新加载Town01，清空当前世界，因此只能独占本地服务器运行，不要同时运行队友的控制程序。程序自行选择至少有35m直道的生成点，创建一辆Model 3、碰撞传感器和后方摄像头。先刹车稳定1秒，以0.25油门加速3秒，再全刹车5秒；转向始终为0。这是固定指令的接口测试，不是自动驾驶策略。

同步模式表示“程序发出一次tick，世界推进0.05秒”，方便把输入和下一帧状态对应起来。每帧记录位置、速度、时间和控制值。`work/carla/control_smoke/`保存`frames.json`、`report.json`、`driving.png`；输出目录可通过`--output`修改。结束时只销毁脚本创建的车辆与传感器，恢复加载后世界的原有推进设置，但不恢复加载前地图。

通过阈值是最高速度大于1m/s、位移大于1m、末速小于0.1m/s、未收到碰撞事件、保存画面且清理无报错。这些只是接口连通性标准。下一步加入静止前车、两车车身净距和速度反馈控制，再实现按距离减速停车。
