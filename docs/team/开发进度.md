## 正式代码实测与问题

本批修正了正式`obstacle.cpp`的前车筛选：不再按纵向距离绝对值将后方、邻道或其他道路目标选为前车，改为仅在同道路同车道前方选择最近目标；纵向位置相同的目标仍保留，避免忽略重叠。依赖地图车道归属正确；跨线目标、弯道和地图失效仍待验证。

正式模式把CARLA直道上的车辆参考点纵向距离转换为生产函数所需的lane-s，传入静止、同道路同车道目标。此处使用继承代码普通分支的caseIdx=2，不代表本届评分ID或官方场景映射。未运行生产Obstacle构造、地图查询、main_follow循环、drive和横向控制。它们的缺陷不会被本实验覆盖。

| 模式 | 初始速度 / 车距 | 最终车身间距 | 最终速度 / 碰撞 | 2m±0.5m辅助验收 |
| --- | --- | --- | --- | --- |
| 正式C++跟车 | 10km/h / 25m | 1.375m | 0 / 无 | 失败 |
| 正式C++跟车 | 30km/h / 60m | 1.468m | 0 / 无 | 失败 |
| 原Python实验规划器，对照 | 30km/h / 60m | 2.150m | 0 / 无 | 通过 |

步长均为0.05s，要求在目标区域内连续停稳至少2s，正式组各运行60s后结束。正式组实际连续静止分别为51.50s、39.45s，但因停在验收区外，区内驻停时间为0；不是车辆没有停下。CSV已逐帧核对正式原始目标与最终执行器转换的输入一致，未被驻停观察器或Python规划器改写。所有实验actor均已清理，世界设置恢复。

正式算法仍使用固定4.38046m距离偏移和旧车型制动距离多项式，普通静止分支的行驶目标固定为3m/s；CARLA车辆尺寸和执行器响应与SimOne不同。当前证据能确认跨平台停车偏差，不能单凭此次实验断言原车型同样偏差，也不能直接把CARLA系数写回参赛参数。运动目标分支仍有最低3.5m/s约束，近距离时可能要求继续前进，已用离线输入暴露，尚未修复或开展移动前车实测。

规则追溯：2027《评分与规则》物理第11页表3要求对车道内静止前车制动停车，碰撞计零分，停车间距1～3.5m扣50分、超过3.5m计零分。这里的2m±0.5m仅沿用辅助工程验收，不能视为官方高分目标；30km/h/60m复用了该条款的初始条件，但不构成官方场景复现或得分结论。

## 先前共用驻停核心实验

三组均以车身之间的距离为准，目标间距2m；验收容差±0.5m、停稳速度不超过0.1m/s均为辅助实验设定，不是赛事官方阈值。前车始终存在，完成驻停后继续制动，不放行撞向前车。

| 初始速度 / 车距 | 仿真步长 | 要求驻停 | 独立测得连续停稳 | 最终车距 | 最终速度 / 碰撞 |
| --- | --- | --- | --- | --- | --- |
| 10km/h / 25m | 0.05s | ≥2s | 2.05s | 2.144m | 0 / 无 |
| 30km/h / 60m | 0.05s | >5s | 5.35s | 2.150m | 0 / 无 |
| 20km/h / 40m | 0.1s | ≥10s | 10.10s | 2.133m | 0 / 无 |

CSV逐帧数据与报告计时已交叉核对；每轮车辆和传感器清理成功，结束后服务端无实验actor、恢复异步模式。报告保存实验参数、源码/动态库哈希、平台版本、地图车型与失败原因；复现实验时同时记录`git rev-parse HEAD`。独立测量与控制器计时可不同：测量器按±0.5m范围计算，控制器在更窄的停车区域内启动；报告分别保留两者。

规则依据：2027《评分与规则》物理第13页表9驻停小于10s计零分；第19页表22、评分ID20驻停不超过5s计零分，因此不能把两种下界混用。对应的精确等号测试通过；这只验证计时能力，不等于完成相关泊车、信号灯或路口场景。策略`.stg`中的stopTime仍解释为最短驻停时间，逐场景如何配置需另行核定。

SimOne的[SimOne_Data接口说明](https://simone-docs.51sim.com/SimOneCpp/struct_sim_one___data/index.html)标明timestamp单位为毫秒；策略循环转换为秒使用，匹配本届SDK时仍需核对其时钟行为。GPS取数失败现在立即返回false，策略循环下发零目标速度并重置驻停计时；其他驾驶模式调用方和SDK发送失败处理尚待补齐。

以上三组使用Python接近规划器，仅共用C++驻停核心；复现时必须指定`--controller experimental`。它们不证明正式跟车算法达到同样效果。此前观察到的末段短暂停下后继续靠近属于这条实验链，不能据此推断正式跟车代码有同样行为。

## 如何复现本批能力

以下命令均在仓库根目录的PowerShell执行，先按团队指南准备64位Python 3.10和MSVC。离线验证无需启动仿真器：

```powershell
py -3.10 -B tools/test_competition_control.py
py -3.10 -B tools/test_competition_manual.py
py -3.10 -B tools/test_competition_neighborhood.py
py -3.10 -B -m unittest tests.test_competition_following tests.test_stationary_stop tests.test_stop_controller -v
```

前三项应退出码0且`passed=true`，最后一项显示`OK`。报告位于`work/competition_control/development/`、`work/competition_manual/development/`和`work/competition_neighborhood/development/`。用`py -3.10 -B tools/test_competition_control.py --revision a5697af --label timing-before`可复现修改前13项失败，预期退出码1；只读取旧源码，不切换工作树。

CARLA实验需下载并解压[官方CARLA 0.9.15 Windows包](https://github.com/carla-simulator/carla/releases/tag/0.9.15)。以下客户端版本与服务端必须一致；CARLA只作辅助开发，不需要赛事平台账号。

首次创建专用Python环境并安装客户端，然后预先验证C++桥接能构建：

```powershell
py -3.10 -m venv work/carla/venv
.\work\carla\venv\Scripts\python.exe -m pip install carla==0.9.15
.\work\carla\venv\Scripts\python.exe -B tools/competition_stop.py
```

最后一条应输出DLL路径和哈希；失败时先处理MSVC组件或输出中的编译日志。各队员输入自己的CARLA路径，启动一个专供本实验使用的服务端：

```powershell
$carlaRoot = Read-Host '输入包含CarlaUE4.exe的目录完整路径（不加引号）'
& (Join-Path $carlaRoot 'CarlaUE4.exe') -quality-level=Low -carla-rpc-port=2000 -nosound
```

等待场景加载，在另一个仓库根目录PowerShell窗口运行：

```powershell
.\work\carla\venv\Scripts\python.exe -B tools/carla_stationary_stop.py --speed-kmh 10 --gap 25 --dwell-seconds 2
```

脚本默认`--controller formal-follow`，连接本机2000端口，必要时加载Town01，生成主车、静止前车和记录相机。不要同时运行其他控制客户端；已有车辆/行人/传感器时会拒绝接管。首次调用自动编译正式函数DLL，默认实时展示，完成后实验车辆清理。当前正式代码预计因停车过近而显示`passed=false`并退出码1，这是已复现的验收失败；`competition_verified`始终为false。若出现连接或编译错误则属于环境问题，按error排查，不能当作同一个算法失败。

终端会显示结果目录：`report.json`含参数、正式源码/动态库/配置哈希、失败原因、实际连续静止时间`stationary_seconds`和区内驻停时间`stop_held_seconds`；`frames.csv`同时保存`formal_target_speed_mps`与最终使用的目标；PNG为过程和结束截图。完成后关闭本轮启动的CARLA窗口。

用相同初始条件对比正式算法和实验规划器。`--no-realtime`取消实时显示等待，仍按仿真时间计时；前一条目前预期失败，后一条预期通过：

```powershell
.\work\carla\venv\Scripts\python.exe -B tools/carla_stationary_stop.py --controller formal-follow --speed-kmh 30 --gap 60 --no-realtime
.\work\carla\venv\Scripts\python.exe -B tools/carla_stationary_stop.py --controller experimental --speed-kmh 30 --gap 60 --no-realtime
```
