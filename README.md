# 智能网联汽车设计赛项开发仓库

本仓库用于四人团队备赛2027年第十届中国大学生工程实践与创新能力大赛虚拟仿真赛道智能网联汽车设计赛项。严格遵守本届正式规则与组委会后续通知，优先借鉴学长代码，以高质量完赛为最终目标。

正式交付包括可在赛事平台运行的驾驶决策、车辆控制与自动泊车程序，以及队员能够复现的构建配置、测试和使用说明。CARLA用于辅助验证与学习；比赛能力以官方平台及评分结果核验。

## 从这里开始

- [正式开发指南](docs/team/README.md)：首次配置、继承开发流程、平台接入、辅助实验与团队协作。
- [团队共享开发进度](docs/team/开发进度.md)：唯一经常更新的状态入口，记录远端代码能力、验证、下一步与阻塞。
- [历史感知模块使用说明](perception/README.md)：模型、视频与离线测试的独立使用方法。

## 工作空间结构

| 目录 | 用途 |
| --- | --- |
| `code_pre/` | 学长交接原件和历史版本；正式开发从选定基线建立独立副本 |
| `tools/` | 环境检查与CARLA辅助实验入口 |
| `tests/` | 针对代码行为的测试；C++工具链探测位于其cpp子目录 |
| `perception/` | 历史视频感知开发副本，不是驾驶控制的数据上游 |
| `docs/team/` | 正式开发指南与团队共享开发进度 |
| `docs/sources/`、`docs/legacy/`、其他docs文件 | 本地规则原文、往年资料与分析，不随公开仓库分发 |
| `work/`、`runs/`、`tmp/` | 本地环境、实验记录、输出与临时文件，不提交 |

新增正式驾驶/泊车代码时，在独立开发目录记录来源与真实构建方法；具体建立状态以开发进度为准。不要在原件目录修复或生成构建文件，也不要为了目录齐全先放入无法运行的工程。

## 规则与公开范围

开发前从[赛事官网](http://gcxl.edu.cn/new/index.html)取得2027届《命题与运行》《评分与规则》及补充通知；历史代码、训练示例和工程参数均服从本届正式要求。

公开仓库包含源码、必要配置、测试、使用说明及已有第三方许可证。原始私人材料、模型、视频、安装包、SDK、许可证、凭据和生成结果留本地；所需外部资料的准备方式见正式开发指南。公开仓库不是全部交接资料备份。

保留原作者和第三方版权声明，未对全部继承代码统一授予新的开源许可证。
