# 智能网联汽车设计赛项备赛代码

用于 2027 年第十届中国大学生工程实践与创新能力大赛虚拟仿真赛道智能网联汽车设计赛项的代码研究与后续开发。当前保存 2025 年交接代码与可阅读历史版本，尚未完成 2027 平台适配或成绩复现。

## 代码入口

当前备赛主线是驾驶决策、控制与自动泊车，先阅读 [开发路线与验证边界](docs/team/开发路线.md)。已保存的2027正式规则要求利用平台提供的感知信息开发决策控制，尚未发现独立视频计数提交要求。[perception](perception/README.md) 是已恢复的历史辅助项目，不作为当前主线。

四人共同开发请先阅读 [团队协作与首次运行](docs/team/README.md)。统一在本地修改并验证，同步远端最新改动后直接推送 `main`。

主基线：`code_pre/2025 智能网联汽车-曾熙桐/代码工程/【20250725.8 Traj】last version/`。

| 部分 | 目录 | 功能 |
| --- | --- | --- |
| 自动驾驶 | 主基线内 `TrajectoryControl/` | 地图路径、障碍物与停止线、跟车、变道、预设策略点 |
| 自动泊车 | 主基线内 `AVP/` | 车位判断、局部坐标、接近/倒车/等待/驶离状态机 |
| 公共工具 | 主基线内 `util/` | 地图示例、纯追踪、第三方解析库 |
| 视频感知 | 主基线相邻的 `感知题代码/` | YOLO 检测、目标关联、方向判断与 Excel 计数 |
| 历史档案 | `code_pre/代码版本管理/` | 校赛、省赛、国赛与参考实现的未压缩源码 |

历史档案中的同名 `last version` 缺少部分 manual/tools 文件，应以交付主基线为准。继承源码目前保留原样，不表示已修复或验证运行。

## 运行前提

C++ 依赖 SimOne SDK，当前 CMakeLists 是子工程，需要 SDK 上层提供头文件、库和构建函数。代码采用 Windows/MSVC 接口及 C++17 特性，尚未验证 Linux。原程序含 `D:/Sim-One/SimOneAPI/ADAS/` 固定路径，需后续适配。

自动驾驶从平台读取车辆、障碍物和地图，计算目标速度与转向后下发。主链使用速度控制模式，`throttle` 单位为 m/s，不是油门百分比。

完整感知推理的 Windows/Python 3.10/CPU 环境已恢复并固定依赖，见 [视频推理运行说明](docs/team/视频推理运行.md)。运行需匹配的 `best.pt` 与输入视频，它们没有上传。历史原版导入即执行；新的 `perception/` 使用显式命令行入口，导入不会启动推理。

感知副本已修复检测框格式、跨类别误抑制、同帧重复编号和距离后备匹配选错近邻的问题。离线测试验证这些局部行为，不代表真实视频准确率。709帧参考视频已完成导出，但有明显误检且计数为0；详细实验记录见视频说明。尚未完成完整 C++ 编译、本届平台运行或官方评分。
