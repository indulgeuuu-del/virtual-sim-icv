# 智能网联汽车设计赛项开发仓库

本仓库用于四人团队备赛2027年第十届中国大学生工程实践与创新能力大赛虚拟仿真赛道智能网联汽车设计赛项。开发严格遵守本届正式规则与后续通知，以高质量完赛为目标。

正式开发围绕驾驶决策、车辆控制、自动泊车和连续场景展开，交付可在比赛平台运行、可供队员共同维护和验证的程序。

## 开始开发

1. 阅读[正式开发指南](docs/team/README.md)，完成配置并了解代码入口、修改和提交方式。
2. 查看[团队共享开发进度](docs/team/开发进度.md)，确认当前开发入口、已验证能力和待办。
3. 对照本届规则完成修改、验证受影响场景，再同步并推送main。

## 仓库内容

| 目录 | 用途 |
| --- | --- |
| `code_pre/` | 交接源码与历史版本，正式开发的参考基线 |
| `competition/` | 团队共同修改的驾驶、泊车与公共工具 |
| `tools/` | 工具链、平台连接检查及辅助实验工具 |
| `tests/` | 已有代码测试与C++工具链探测程序 |
| `docs/team/` | 正式开发指南与共享开发进度 |

`perception/`保留历史视频感知代码，CARLA脚本用于辅助实验，均不代表正式比赛程序或官方评分验证。
